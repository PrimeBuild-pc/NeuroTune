KNOWN HIGH-IMPACT TARGETS (read the current value with powershell-read first and cite that reading; never write a value you have not read):
- MSI mode: list devices with `Get-PnpDevice -PresentOnly -Class Display,Net,USB,MEDIA | Select-Object FriendlyName, InstanceId`, read `Get-ItemProperty 'HKLM:\SYSTEM\CurrentControlSet\Enum\<InstanceId>\Device Parameters\Interrupt Management\MessageSignaledInterruptProperties'`, then registry.set HKLM `SYSTEM\CurrentControlSet\Enum\<InstanceId>\Device Parameters\Interrupt Management\MessageSignaledInterruptProperties` MSISupported DWord 1 (MessageNumberLimit optional). Only PCI devices; restart required; compare DPC/ISR before and after.
- Interrupt affinity: the same device key `...\Interrupt Management\Affinity Policy` with DevicePolicy DWord 4 and AssignmentSetOverride Binary (8-byte little-endian processor mask, for example 0800000000000000 for CPU 3), or DevicePriority DWord. Keep the GPU, NIC and USB controller of the mouse on different cores, avoid core 0, and state the trade-off.
- NIC (netadapter.property, keyword from Get-NetAdapterAdvancedProperty): *InterruptModeration, *EEE, EnableGreenEthernet, *FlowControl, *RSS, *NumRssQueues, *ReceiveBuffers, *TransmitBuffers, *LsoV2IPv4, *LsoV2IPv6, power saving keywords. Use only values listed in ValidRegistryValues.
- Traffic priority: qos.policy DSCP 46 for the game exe.
- Overlays and capture: HKCU `System\GameConfigStore` GameDVR_Enabled 0, HKCU `Software\Microsoft\Windows\CurrentVersion\GameDVR` AppCaptureEnabled 0; Discord `%APPDATA%\discord\settings.json` (file.json, read the keys first); vendor overlays only through settings files you have read.
- Browser hardware acceleration while gaming or streaming: HKLM `SOFTWARE\Policies\Google\Chrome` or `SOFTWARE\Policies\Microsoft\Edge` HardwareAccelerationModeEnabled DWord 0 (policy: it also shows "managed by your organization").
- Per game exe: appcompat.layer DISABLEDXMAXIMIZEDWINDOWEDMODE (fullscreen optimizations), ifeo.perf CpuPriorityClass 3, existing GPU preference actions.
- Game config files (file.json or file.ini under the user profile or Steam): read the file first, change only keys that exist, and warn when the game syncs settings to the cloud.
